# WHICH Choice Short Visual Identity

## Purpose

WHICH의 실제 질문 하나를 5초 안에 보여주고, 시청자가 A/B 중 하나를 즉시 고른 뒤 서비스에서 결과와 이유를 확인하도록 유도한다. 반복 제작을 전제로 하며 질문과 선택지만 교체해도 같은 품질을 유지한다.

## Brand palette

- Deep navy `#102F35`: 신뢰감 있는 기본 배경
- Teal `#087F88`: 선택지 A와 브랜드 신호
- Orange `#FF6B35`: 선택지 B와 강한 대비
- Lime `#D9F36C`: 진행선과 행동 유도 강조
- Ice `#F3F8F7`: 마지막 장면의 밝은 전환
- Cyan `#72DBE0`: 원형 모티프와 보조 강조

## Type

- 한국어 본문과 큰 질문: Pretendard, 900/350의 극단적 굵기 대비
- 메타 라벨: JetBrains Mono, 800, 넓은 자간
- 세로 영상에서 2초 안에 읽을 수 있도록 질문을 제외한 문구는 짧게 유지한다.

## Layout

- 1080 × 1920 세로, 30fps, 5초
- 모든 장면은 좌측과 하단에 고정된 축을 사용한다.
- 각 장면은 배경, 본문, 원형 또는 대형 문자 장식의 세 레이어를 갖는다.
- A와 B는 동일한 정보량과 시각적 무게를 갖는다.

## Motion

- 0–1.4초: 질문을 빠른 스케일 인으로 제시한다.
- 1.2–2.6초: A 장면이 오른쪽에서 밀고 들어온다.
- 2.4–3.8초: B 장면이 반대 방향에서 밀고 들어온다.
- 3.6–5초: 원형 아이리스로 WHICH CTA를 공개한다.
- 새 장면의 전환이 이전 장면의 퇴장을 대신한다. 마지막 장면만 페이드 아웃한다.
- 애니메이션의 첫 움직임은 0.14초에 시작하며, 모든 동작은 결정적이고 재현 가능해야 한다.

## Content safeguards

- 운영 WHICH DB의 공개 질문과 선택지만 사용한다.
- 확인되지 않은 투표율, 참여자 수, 우세 선택지는 표시하지 않는다.
- 외부 이미지와 개인 취향을 드러내는 특정 게임·작품 예시는 기본 템플릿에 넣지 않는다.
- 기본 템플릿은 무음 키네틱 타이포그래피이며 외부 생성형 영상·TTS 호출 비용이 없다.
