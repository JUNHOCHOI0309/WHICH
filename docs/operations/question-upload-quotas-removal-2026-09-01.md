# 질문·이미지 작성량 제한 제거

## 결정과 범위

2026-09-01 사용자 요청: 글 작성과 이미지 등록에 별도 횟수 제한을 두지 않는다.

- 텍스트·승인 Library 질문 및 비공개 이미지 제출의 24시간 3개 한도 제거.
- 이미지 업로드 세션의 Member 3회/24시간, IP 12회/24시간 한도 제거.
- Member 이미지 보관 자산 10개 한도 제거. 기존 자산이나 감사 이력은 삭제하지 않는다.
- 작성 화면의 `24시간 최대 3개` 안내 제거.
- API의 `limits.dailyUploads`, `limits.maximumOpenAssets`는 `null`로 무제한을 표현하며 Web·Mobile 계약도 일치시킨다. 비활성 업로드 서비스의 0 값은 계속 비활성 상태를 나타낸다.
- 불필요한 일일 횟수·보관 개수 집계 쿼리를 제거한다.

## 유지하는 경계

- 로그인·계정 상태·이미지 Pilot capability·현재 동의·제출 소유권 및 상태 검증.
- 파일당 10MB, MIME·픽셀·정규화 검증, 비공개 staging 및 안전 검사.
- 10분 일회성 업로드 토큰, 동시 활성 세션 1개, 중복 제출 방지와 revision 잠금.
- 검사 처리 여력 장애 게이트, AI 호출·비용 한도, 자동 공개의 별도 승인 경계.
- 신고·로그인 남용 방지 및 포인트 적립 한도는 이 변경 대상이 아니다.

AI 검사 한도 소진이나 검사 실패를 통과로 간주하지 않는다. 이 변경은 자동 검사 예약이나 자동 공개를 활성화하지 않는다.

## 검증

- 동일 Member가 같은 날 일반 질문 6개 및 별도 비공개 제출 6개를 생성할 수 있는 API 통합 테스트.
- 보관 자산 11개가 있는 Member가 같은 IP에서 업로드 세션 14개를 순차 생성·소비하는 통합 테스트.
- 동시 세션·잘못된 토큰·재사용·OFF·동의·capability·다른 제출 소유권 및 취소 상태 보호 회귀 테스트.
- Web의 기존 횟수 안내 제거 및 직접 업로드, Mobile의 nullable limits 응답 테스트.

운영 DB 마이그레이션, grant 변경, 기존 제출 재전송 및 AI API 호출은 필요하지 않다.
배포 증빙은 PR의 실제 CI·Cloud Build·Cloud Run revision 결과로 기록한다.
