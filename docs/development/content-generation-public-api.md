# 콘텐츠 생성용 공개 Issue API

WHICH 운영 데이터베이스를 외부 도구에 직접 연결하지 않고, 공개 가능한 질문만 읽기 위한
웹 BFF 엔드포인트입니다.

```http
GET https://whichone.site/api/public/issues?limit=3
```

- `limit`: 선택 사항, 1~500 사이의 정수이며 기본값은 100입니다.
- 인증이나 쿠키는 필요하지 않습니다.
- 공개 중이고 투표가 열려 있으며 피드 노출 가능·저위험·비정치로 판정된 최신 질문 버전만
  반환합니다.
- 질문, 맥락, 카테고리, 공개 시각, 2~4개 선택지와 공개 승인된 이미지 정보를 반환합니다.
- 이미지가 없거나 공개 조건을 충족하지 못하면 `media` 또는 `contextMedia`는 `null`입니다.
- 결과·투표 수·작성자 개인정보·내부 검수 정보는 반환하지 않습니다.
- GET 이외의 데이터 변경 메서드는 제공하지 않습니다.

성공 응답은 짧게 CDN 캐시되며, 원본 API 장애나 잘못된 입력에는 캐시하지 않습니다. 외부
콘텐츠 생성 도구에서 읽을 수 있도록 `Access-Control-Allow-Origin: *`를 사용하지만, 응답 내용은
이미 일반 방문자에게 공개 가능한 데이터로만 제한됩니다.
