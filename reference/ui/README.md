# WHICH UI 디자인 참고 자료

이 폴더의 이미지는 WHICH 웹·모바일 UI를 설계하거나 구현할 때 방향성을 확인하기 위한
참고 시안입니다. 확정된 화면 명세나 그대로 복제해야 하는 구현 요구사항은 아닙니다.

## 시안

- `디자인 시안1.png`: 네온 옐로·퍼플을 강조한 고대비 방향
- `디자인 시안2.png`: 시안 1과 같은 정보 구조에 시안(Cyan)·민트 계열을 적용한 방향

두 시안 모두 데스크톱의 좌측 내비게이션, 중앙 투표 콘텐츠, 우측 보조 정보 구조와
모바일의 투표·결과·댓글·피드 흐름을 함께 보여줍니다.

## 채택한 방향

- 기본 구조는 `디자인 시안2.png`의 Deep Navy 중심 정보 위계를 사용합니다.
- Choice 색상은 시안의 Cyan–Mint 대신 **Cyan–Orange**를 사용합니다.
- 기본 Token은 Deep Navy `#061923`, A Cyan `#14C8D4`, B Orange `#FF8A3D`, Off White
  `#F6F8F7`입니다.
- A/B는 같은 면적과 채도로 표시하고 Label, 경계와 Focus State를 함께 제공해 색상에만 의존하지
  않습니다.

## 사용할 때의 원칙

- 화면 구성, 정보 위계, 투표 인터랙션, 반응형 전환을 위한 참고 자료로 사용합니다.
- 실제 구현은 승인된 제품 요구사항과 데이터·API 계약을 우선합니다.
- 색상 대비, 키보드 조작, 스크린 리더 등 접근성 기준을 별도로 검증합니다.
- 시안 속 문구, 수치, 사용자 이미지와 순위는 예시 데이터로 취급합니다.
- 새로운 화면도 채택된 Cyan–Orange Token과 동일한 선택 위계를 우선합니다.
